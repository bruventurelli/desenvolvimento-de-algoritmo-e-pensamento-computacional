# Calculadora 20 Funções - Flowgorithm

Projeto desenvolvido para a disciplina de Desenvolvimento de Algoritmo e Pensamento Computacional. Consiste em uma calculadora estruturada no software Flowgorithm contendo 20 operações matemáticas e lógicas, acessíveis por meio de um menu interativo.

## Funcionalidades
O sistema apresenta um menu de repetição contendo as seguintes operações:
1. Cálculo de IMC (Requisito Obrigatório)
2. Cálculo de Área de um Retângulo (Requisito Obrigatório)
3. Soma
4. Subtração
5. Multiplicação
6. Divisão
7. Média Aritmetica
8. Porcentagem
9. Conversão: Celsius para Fahrenheit
10. Conversão: Fahrenheit para Celsius
11. Verificação de Par ou Ímpar
12. Maior entre dois números
13. Cálculo de Idade
14. Velocidade Média
15. Juros Simples
16. Perímetro de um Retângulo
17. Volume de um Cubo
18. Tabuada
19. Potência
20. Fatorial

## Conceitos Aplicados
- Entrada e saída de dados.
- Uso de variáveis numéricas (Inteiros e Reais).
- Estruturas de decisão (Se/Senão).
- Laços de repetição (Faça/Enquanto) para o funcionamento do menu.

## Como Executar
1. Certifique-se de ter o [Flowgorithm](http://www.flowgorithm.org/) instalado em sua máquina.
2. Abra o arquivo `calculadora.fprg`.
3. Clique no botão verde de execução (Play) na barra de ferramentas superior.
4. Utilize o console para navegar pelas opções do menu digitando o número correspondente à operação desejada.
